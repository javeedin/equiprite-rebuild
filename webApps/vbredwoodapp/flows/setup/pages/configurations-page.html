TIMESHEETS
Master costing switch. ON: hours/utilization costing is available (per-subclass). OFF: bill on the complete request period only — hours are not used anywhere.
FUSION PPM RATES
ON: Fusion prices rentals from its own PPM rate schedules and the Post Cost screen is withdrawn. OFF: EquipRite prices them from its rate schedules, as today. Requires Timesheets to be ON — an approved timesheet is what sends hours to Fusion, so without it nothing would post. Posting to Fusion is not built yet — turning this on stops EquipRite costing without yet replacing it.
SEND NON-LABOR RESOURCE = EXPENDITURE TYPE
ON for Oceaneering: their resource is named exactly like the expenditure type, and their Usages entries require one. The resource's organization is the expenditure organization above.
PROJECT ENABLED FOR EXTERNAL CUSTOMERS
External Project Assign. Let the equipment manager attribute a customer-raised request to an internal project and task for costing. ON: the Assign Project action appears on the request detail page, and project + task are required before the request can be confirmed (editable only until the first line is allocated). OFF: no project is captured on customer requests.
QUOTES
Which request flows can raise a quote. Internal project requests always carry a project; external customer requests may or may not.

Expenditure Types
Which Fusion expenditure types each piece of equipment bills under. A timesheet offers every type the project may be charged under — hundreds of them — and these mappings narrow that to the two or three that belong to the equipment on the row. Unmapped equipment still shows the full list, so nothing breaks while this is incomplete.
