Receiving closes each ticked line on its own, so the rest can come in later. Its units go back to stock (serials Available, lots and items Active); a unit that cannot be released is named in the message and stays Rented until someone releases it. The request closes when its last line does.

For equipment returned without prior notice. Scan the unit, or search by equipment, model, class, request or project. The return then follows the normal path: a return transfer order, and the line is received here when it reaches the yard.
