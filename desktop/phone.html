EquipRite on your phone

Scan a code with the phone's camera. EquipRite opens and offers to put itself on the home screen, like an app.

From VBCS Recommended

The deployed app: install it on the home screen; the camera (scanning tags) and the phone's location work. Any phone, anywhere.

Paste EquipRite's VBCS address below to get its code.

Open EquipRite Next (or Mobile) on VBCS in a browser and copy its address. It is kept on this PC only.

From this PC, over Wi-Fi To try it now

No deployment needed: this PC serves EquipRite Mobile to a phone on the same Wi-Fi, while EquipRite runs here.

Switch on to get the code.

The phone works as you (the person signed in here), so only a phone that scans this code can connect, until you switch it off or quit EquipRite. Windows may ask to let EquipRite on the network: allow Private networks only. Over Wi-Fi the camera and the phone's location are not available (they need the secure VBCS address).

Then, on the phone

1. ScanOpen the camera and point it at a code. Tap the link that appears.
2. Your tabsEquipRite opens with the tabs your role has: Approve, Pick, Request, My requests (from VBCS, after signing in).
3. Add to home screeniPhone: Share, then Add to Home Screen. Android: Install when asked, or ⋮ then Install app.

EquipRite Mobile is not built on this PC yet: run "npm run desktop:fresh", then open this again.
