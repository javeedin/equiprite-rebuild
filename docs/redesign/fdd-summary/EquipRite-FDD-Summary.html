1EquipRite at a glance

EquipRite is a PaaS extension for Oracle Fusion Cloud ERP that manages the equipment lifecycle for construction, engineering and oil & gas project organisations: request from a catalog, allocation and approval, picking and shipping via Transfer Orders, usage timesheets, rate-based costing, intercompany and AR billing, and return (1.1). It covers heavy equipment, small tools, bulk items and consumables.

In scope (2.1)

  • Equipment master with Inventory and Fixed Assets
  • Optional rental agreements (internal, external, project, class)
  • Rate schedules with six tiers
  • Request cart, allocation (auto/manual), approval
  • Initiate Picking (TO + reserve + pick release), optional job
  • Gantt and map schedule
  • Oracle mobile picking and shipping
  • Optional inspections
  • Weekly time entry and approval
  • Costing, IC billing, AR invoices, PPM posting
  • Return via reverse TO and settlement
  • Analytics; role-based security

Out of scope (2.2) and later (2.3)

  • Fixed Assets configuration
  • IFRS 16 / ASC 842 lease accounting (later)
  • EPM CapEx planning (later)
  • Native mobile app (responsive web only); offline PWA later
  • GPS / telematics, IoT usage (later)
  • Operator HR management
  • Barcode / RFID scanning at yards
  • Predictive maintenance (later)
  • Asset retirement and disposal, BR-010 (later)

Inventory organisations (3.3)

Equipment lives in an Equipment Yard inventory org (subinventories Available, Reserved, Maintenance) and moves to a Project Site virtual org through inter-org Transfer Orders; returns use a reverse TO. Project sites can have sub-inventories (region/state/city) and locators per project, e.g. TEXAS.PRJ-2026-001 (7.17.2D). All of this is on only when TRANSFER_ORDERS_ENABLED = Yes for the business unit. Intransit ownership is FOB Shipment or FOB Receipt (OI-05).

5End-to-end process (5.1–5.5)

Phase 1 · Agreement & rate setup

  • Define categories, serial/lot control (Inventory)
  • Set up rate schedules (always on)
  • Set up agreements (optional)
  • Approve and publish rates/agreements
  • Manage equipment master, link Fixed Assets

Phase 2 · Request, allocation & approval

  • Raise request (project/customer, optional agreement)
  • Submit: DRAFT → IN_PROCESS, NTF-01
  • Optional allocation: Auto Allocate or manual
  • Approve: IN_PROCESS → APPROVED, or REJECTED

Phase 3 · Pick, ship & receive

  • Initiate Picking: TO + reserve + pick release
  • Optional automatic job
  • Warehouse picks on Oracle mobile
  • Optional inspection
  • Ship confirm, Bill of Lading, in transit
  • Receive per line at site; billing starts; DEPLOYED

Phase 4 · Usage, costing & billing

  • Weekly timesheets
  • Rate engine picks the rate period
  • Timesheet approval (bulk)
  • IC invoice or AR invoice
  • Post to GL

Phase 5 · Return & settlement

  • Return TO, site → yard
  • Ship from site, receive at yard
  • Post-return inspection, WO if needed
  • Stop billing, reconcile, damage charges
  • Final settlement, archive

Line-level statuses also include INSPECTION_FAILED (DP-03). Cancelled requests (DRAFT or IN_PROCESS only) are hidden by default (7.6.3).

Timesheet (7.14.2)

DRAFT → SUBMITTED → APPROVED, or REJECTED → DRAFT. Approvers may adjust hours with an audit trail.

Agreement (7.3A.2)

DRAFT → ACTIVE → EXPIRED, or CANCELLED. Only ACTIVE agreements can be linked.

Procurement requisition (7.5.6A)

SUBMITTED → APPROVED / PROCUREMENT_IN_PROGRESS → FULFILLED, or ALTERNATIVE_SUGGESTED, or REJECTED.

Inspection result (7.12.4)

PASS → ship. CONDITIONAL → EM acknowledges. FAIL → INSPECTION_FAILED: substitute, work order or cancel the line.

Certification (7.2.5A)

ACTIVE (green) → EXPIRING (amber, 30 days before) → EXPIRED (red).

Postings and transfers

Direct cost, inventory consumption and transfers: PENDING → POSTED / COMPLETED, or FAILED (retry).

17Inconsistencies to resolve in the FDD

Found while summarising. Each needs a decision before the matching feature is built.

  1. Roles differ between sections: 2.1 names five personas (Requester, Project Manager, Equipment Manager, Timekeeper, Time Approver); 10.1 defines four roles (Project Manager, Equipment Manager, Finance/AR, Operations Lead); 7.1.2 adds Warehouse Operator and System Administrator; 10.3 adds External Customer.
  2. Notification IDs NTF-08, NTF-09 and NTF-10 are used twice (section 11 table and 11.2). NTF-21 (procurement, 7.5.6A) is not in section 11. BR-014 says 17 event types.
  3. Reports are numbered differently in section 12 (RPT-01 to RPT-07) and section 7.15 (RPT-01 to RPT-20). The 7.15 introduction says 15 reports; it defines 20.
  4. Retry timing differs: DP-10 says 3 retries at 30 s, 2 min, 10 min; 9.3.1 says 1 s, 3 s, 9 s for HTTP 5xx.
  5. Automatic picking: 5.3 step 3.2 and DEC-08 describe an EquipRite scheduled job; 7.16.6 says auto picking is handled by Oracle Fusion standard functionality.
  6. Error log integration_id and the health dashboard cards cover INT-01 to INT-10, but there are 20 integrations.
  7. Timesheets store Monday–Friday quantities (mon_qty–fri_qty), while WEEK_END_DAY allows Saturday or Sunday week endings.
  8. NTF-02 says the Transfer Order is created on approval; since v1.2 it is created at Initiate Picking.
  9. The request list status filter (7.6.1) omits PICK_INITIATED, PICK_RELEASED, SHIPPED and CLOSED, and includes CANCELLED, which is not in the status lifecycle (5.6).
  10. Performance targets differ: BR-014 says page load ≤ 2 s; section 13 says < 3 s at the 95th percentile.
  11. Document control still shows Version 1.3 while the revision history runs to 1.7.
