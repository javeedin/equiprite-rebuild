EquipRite, redesigned on Oracle Redwood

One app shell for every role, organised around the five phases of the equipment lifecycle. Each screen below names its FDD section and the Redwood page template it would be built with. Nothing is coded yet: these are for review.

What changes from today

One shell, one menu Header with the global Region / Inventory Org filter (§7.1.1), search, cart and notifications on every page. Side menu grouped by phase; items hide by role and by module flag.
Home is a work queue KPI bar plus role tiles with live counts (§7.1.2–7.1.3). Every number opens the filtered list behind it.
Requesting is a cart Three steps: pick equipment from the catalog, set project or customer, review and submit (§7.5). Templates and agreements fill the cart in one click.
One workbench for the Equipment Manager Tabs by stage: to approve, to pick, in transit, deployed, returns, procurement. Approve & allocate opens from it, with the schedule embedded (§7.8, §7.11).
Status is always visible A lifecycle tracker on every request (§5.6) and the same status colours, soft/hard reserve blues and source badges on every list.
The old app stays Today's app is not changed. The sign-in window offers Old EquipRite and New EquipRite and opens the one chosen; both use the same data.
Standard Redwood pages Lists use the Smart Search page, records the General Overview page, edits a drawer, Home the Dashboard Landing page: the oj-sp templates the app already uses.
